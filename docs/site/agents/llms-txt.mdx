Tessy publishes machine-readable files so an agent can use it without a connector.

| URL | What it is |
|---|---|
| [`tessy.page/llms.txt`](https://tessy.page/llms.txt) | Short guide: the one-link `/new` flow, the page file, MCP and REST entry points. |
| [`tessy.page/llms-full.txt`](https://tessy.page/llms-full.txt) | The connect guide and the page file format in one request. |
| `tessy.page/<username>/llms.txt` | A Markdown version of any published page. |
| [`tessy.page/api/v1/public/<username>`](https://tessy.page/api/v1/public/example) | Any published page as JSON. |
| [`tessy.page/openapi.json`](https://tessy.page/openapi.json) | OpenAPI 3.1 description of the REST API. |
| [`tessy.page/schema/page.schema.json`](https://tessy.page/schema/page.schema.json) | JSON Schema of the full page. |
| [`tessy.page/schema/brief.schema.json`](https://tessy.page/schema/brief.schema.json) | JSON Schema of the short [page file](/agents/format). |

These docs also serve their own `/llms.txt` and `/llms-full.txt`. On a self-hosted instance the Tessy files use your own address.

## The one-link flow

An agent that can only write text can give the user a normal link:

```
https://tessy.page/new?name=Mira%20Sol&bio=Illustrator&links=https://github.com/mira,hi@mira.so,mira/atlas
```

It opens a live preview and one button makes the page theirs.
